# Ebook Writing Framework (topic-agnostic)

One framework, any topic. The concept never changes: **a beginner-friendly, honesty-first
playbook that trades a clear numbered system for the reader's willingness to work.**
Only the subject matter swaps.

## When to use

- "Write an ebook / book / guide / playbook about X."
- "Turn these X threads / notes / transcripts into an ebook."
- "Outline the chapters for my ebook."
- Re-skinning an existing playbook for a new niche or market.

## The deliverable set

1. `outline.json` — the structured manuscript (see `references/outline-schema.md`).
   This is the source of truth; prose lives inside it.
2. Paid PDF + free-sample PDF — generated by `scripts/build_from_outline.py`.
3. (Optional, downstream) the commercial wrapper — sales site, covers, ads, paywall —
   lives in the companion skill `digital-product-launch`. Hand it the finished PDF.

## Workflow

1. **Mine the source.** Existing threads/notes/docs? Extract claims, steps, numbers and
   links; keep provenance per item (you will cite per chapter). Nothing to mine? Interview
   the client or draft from domain basics — same anatomy applies.
2. **Fix the promise.** One sentence: who + what outcome they work toward + by what
   system. Every chapter must serve it. Reject guaranteed-outcome phrasing.
3. **Lay the 10-beat arc** (`references/arc-and-anatomy.md`), mapping your topic onto each
   beat. If a beat genuinely doesn't exist for the topic, merge it — never pad.
4. **Draft inside the chapter anatomy.** Promise → sections → myth-bust → task → sources.
   Write to the voice rules (`references/voice-and-honesty.md`) as you go, not after.
5. **Add the devices** (`references/devices.md`): worksheets, 30-day plan, tracker,
   appendix of sources. These are what make a playbook feel worth paying for.
6. **Emit `outline.json`, build, verify.** Page counts per beat (~3–4 pages/chapter,
   ~35–40 pages total). Read the sample PDF's CTA page: chapter 1 must end wanting more.
7. **Attribution & claims pass** (`references/voice-and-honesty.md` §Ethics) before anyone
   sees it: every borrowed idea cited, every earnings claim framed as a target.

## Non-negotiables

- **Honesty doctrine.** State the work. Include "what this is NOT". Name who should put
  the book down. This is both ethics and the brand's conversion engine.
- **Every chapter ends in action.** A chapter without a DO-THIS-NOW box is unfinished.
- **Every borrowed idea ends in a citation.** Per-chapter references box + appendix.
- **Sample = chapter 1 only**, ending on a CTA page. One public taste, rest gated.
- **Numbers beat adjectives.** ₦/€/$ amounts, day counts, page counts, checklists.

## Scripts

- `scripts/build_from_outline.py outline.json --out DIR` → `book.pdf` + `sample.pdf`
  (fpdf2; A4; DejaVu; numbered footer; cover; contents; appendix). Verify with the
  page-count parse, never with stdout alone.
- `examples/outline.example.json` — a complete worked outline on a DIFFERENT topic
  (freelance writing) so you can see the framework carry a new subject.

## Gotchas

- DejaVu renders `₦ ✓ ✗ ·` but NOT colour emoji — keep the `clean()` stripper.
- Chapter 1 carries double duty (sample); make it self-contained AND incomplete-feeling.
- Don't write the 30-day plan as prose; it must be a scannable day/week grid.
- Keep paragraphs ≤ 4 lines at 10.8pt/6.3mm or the page turns to mud.
- If the topic is regulated (finance, health, law), add the disclaimer block from
  `references/voice-and-honesty.md` and soften every outcome claim one more notch.
